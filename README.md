# Персональний Тренер — MVP (мобайл-фьорст сайт)

## Файли
- `index.html` — весь застосунок в одному файлі (працює навіть офлайн, дані в localStorage)
- `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png` — для встановлення як PWA

## Як подивитися зараз
Просто відкрий `index.html` у браузері (краще на телефоні або у мобільному режимі DevTools).

## Як опублікувати
Залий усі 5 файлів на будь-який статичний хостинг: Netlify Drop, Vercel, GitHub Pages, Cloudflare Pages.
Після публікації на телефоні зʼявиться «Додати на головний екран» — сайт поводитиметься як застосунок (офлайн, іконка, повний екран).

## Шлях до iOS/Android апки
Той самий код обгортається без переписування:
1. `npm init -y && npm i @capacitor/core @capacitor/cli`
2. `npx cap init "Персональний Тренер" com.example.trainer --web-dir .`
3. `npx cap add ios && npx cap add android`
4. `npx cap open ios` / `npx cap open android` → збірка в Xcode / Android Studio
